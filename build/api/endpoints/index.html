API Endpoints

Here are the core endpoints available in the Cortana API.

Base URL

All endpoints are relative to https://api.cortana.dev/v1

Agents

List Agents

GET/agents

Retrieve a list of all available agents in your organization

Parameters

NameTypeRequiredDescription
limitintegerNoMax number of agents to return (default: 20)
offsetintegerNoPagination offset
statusstringNoFilter by status: active, paused, archived

Create Agent

POST/agents

Create a new agent with specified configuration

Parameters

NameTypeRequiredDescription
namestringYesAgent display name
modelstringYesLLM model ID (e.g., 'gpt-4', 'claude-3')
system_promptstringNoCustom system prompt
temperaturenumberNoSampling temperature (0.0-2.0)

Get Agent

GET/agents/:id

Get detailed information about a specific agent

Parameters

NameTypeRequiredDescription
idstringYesAgent unique identifier

Update Agent

PATCH/agents/:id

Update agent configuration

Parameters

NameTypeRequiredDescription
idstringYesAgent unique identifier
namestringNoUpdated display name
system_promptstringNoUpdated system prompt
statusstringNoSet status: active, paused, archived

Delete Agent

DELETE/agents/:id

Permanently delete an agent and its history

Parameters

NameTypeRequiredDescription
idstringYesAgent unique identifier

Tasks

Create Task

POST/tasks

Assign a new task to an agent for execution

Parameters

NameTypeRequiredDescription
agent_idstringYesTarget agent ID
inputobjectYesTask input data payload
callback_urlstringNoWebhook URL for completion notification
timeoutintegerNoMaximum execution time in seconds

Get Task

GET/tasks/:id

Retrieve task status, result, and metadata

Parameters

NameTypeRequiredDescription
idstringYesTask unique identifier

List Tasks

GET/tasks

List tasks with optional filtering

Parameters

NameTypeRequiredDescription
agent_idstringNoFilter by agent ID
statusstringNoFilter by status: pending, running, completed, failed
limitintegerNoMax number of tasks to return

Cancel Task

DELETE/tasks/:id

Cancel a pending or running task

Parameters

NameTypeRequiredDescription
idstringYesTask unique identifier
Rate Limits

API requests are limited to 100 requests per minute per API key. Exceeding this limit will result in a 429 Too Many Requests response.
